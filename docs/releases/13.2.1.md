## Changes since 13.1.2

- Fixed reply previews in Zulip mobile clients. A link to the original
  message now shows its sender and a short excerpt.
- Improved push notification text for replies by separating the sender
  name from the excerpt.
- Updated the upstream release reference to Zulip Server 13.2. The
  PostgreSQL installation fix from that release was already included in
  the fork's 13.1.2 release.
- Restored screenshots in the README and the 13.1.1 and 13.1.2 release
  notes. Releases now also include their screenshots as downloadable
  assets when available.
