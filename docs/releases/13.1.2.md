## Changes since 13.1.1

- Direct messages now appear above channels in the left sidebar. Open **more conversations** to browse older direct messages.
- Direct message rows show conversation names without message previews.
- Users without a profile photo use their organization's configured default avatars again.
- In Modern, turn profile and channel pictures on or off under **Personal settings → Preferences → Left sidebar**.
- Short conversations keep the latest message beside the compose box. Resizing the composer preserves your reading position when you are farther up the conversation.
- Updated the version history to document two fixes already present in the fork: PostgreSQL startup on new installations and event filtering in several webhook integrations.
