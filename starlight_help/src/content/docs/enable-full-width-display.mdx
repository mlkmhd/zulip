Zulip can use the full width of wide screens or limit the width of the center
message pane for shorter lines. You can configure the display width in your
preferences.

### Enable full width display

<FlattenedSteps>
  <NavigationSteps target="settings/preferences" />

  1. Under **Information**, select **Use full width on wide screens**.
</FlattenedSteps>
